Listing contains config.json and diffusion_pytorch_model.safetensors; no weights downloaded. Actual inference, training and evaluation files are available, despite future-tense wording in the paper abstract.

The external entry accepts full ERP RGB as image/folder/video, with a fixed internal ERP/cubemap mapping. No raw-fisheye or standalone pinhole support, measured calibration, IMU or supplied poses is established. The model adapts DepthCrafter with progressive spherical noise and cube-rectified temporal features. Default inference uses5denoising steps and110-frame windows with25-frame overlap. Its *_disparity.npy is the channel-averaged relative inverse radial-distance map, with scale-and-shift ambiguity. Visualization alone normalizes min/max. There is no direct metric point-map or pose output.

The September10 evaluator correction preserves per-clip LAD2 scale/shift fitting but changes disparity inversion: bounded(default) clamps and clips into0.1-80m, legacy reproduces original conversion. Neither protocol supplies metric scale at deployment. PaperTable2 and current bounded README scores must not be compared as one protocol. Paper main test is held-out outdoor PanoCARLA; indoor examples are qualitative. Real GenEx reprojection uses estimated ViPE/MapAnything poses and ViPE depth alignment, not independent truth. No direct DAP comparison found. Reported31GB/10GB offload memory is author data, not local measurement.

Original standalone components useApache-2.0, but DepthCrafter-derived inference/weights are limited toacademic/research/education and excludecommercial/productionuse; SVD base-model terms apply separately. Do not flatten the entire pipeline toApache-2.0.
